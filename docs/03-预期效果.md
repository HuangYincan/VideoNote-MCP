# 03-预期效果

## 能力清单

使用前后对比：

| | 之前 | 之后 |
|---|------|------|
| 生成视频笔记 | 启动后端 → Web UI → 粘贴链接 → 等任务 → 复制 Markdown | agent 一句「生成这个视频的笔记」即可完成 |
| 对笔记提问 | 需要后端 RAG 接口 + ChromaDB | agent 直接读 Markdown 回答 |
| LLM 配置 | Web 设置页填写 | 终端 `videonote providers set/add`；MCP `get_config` 只读，凭证不进对话 |
| 转写引擎 | 设置页切换 | 终端 `videonote transcriber set`；MCP `get_config` 查看状态 |
| 平台支持 | 同上（YouTube/B 站/抖音/快手/本地/小宇宙） | 一等平台含小宇宙（官方文稿优先）与小红书（原生笔记页 + 扫码登录）；其余 generic yt-dlp |
| 多格式导出 | 依赖额外指引与模板 | 字幕/JSON 确定性导出；随包 LaTeX/Typst 模板供 agent 排版，PDF 需本机实际编译 |
| 前端/Web 依赖 | FastAPI + React 全栈 | **零**，纯 Python MCP |

## 交付物

1. **独立仓库 `VideoNote-Mcp`**（可推送到 GitHub），包含：
   - `videonote_mcp/` —— FastMCP server，10 个工具；
   - `app/` —— 内嵌的 vendored 核心流水线；
   - 独立 MCP 配置直接注册工具；`.claude-plugin/marketplace.json` 仅作可选 MCP 安装入口，不包含 Skills；
   - `videonote_mcp/templates/` —— 三套独立排版模板、配套资源和原许可证，不依赖 Skills；
   - `docs/` —— 中文文档；
   - `pyproject.toml` + `install.sh` —— 一键安装。
2. **安装体验**：`uv sync` 装依赖 → `claude mcp add` / MCP JSON 注册，即可在 Claude Code 中使用。

## 验收标准

- [ ] `uv sync` 能干净安装，`videonote` 启动后 `health_check` 返回 ffmpeg/db/whisper 状态。
- [ ] MCP 注册后 `/mcp` 能看到 `videonote` 及 10 个工具（CI 有名单断言，漂移会红）。
- [ ] 端到端：对本地音频/视频文件或一个短视频链接，`generate_note` → `task` 轮询返回 Markdown，且 agent 能仅凭该 Markdown 回答用户问题。
- [ ] 配置闭环：在终端 `videonote providers set` 填 key → `videonote providers test <id>` 检测模型 → 用该供应商生成笔记成功；MCP 不提供凭证写入工具。
- [ ] 转写切换：终端配置 Groq 凭证并执行 `videonote transcriber set groq` 后，`get_config` 返回对应引擎，任务走云端转写。
- [ ] 初始化与排错：MCP 初始化、`health_check` / `get_config` 返回官方来源与版本；失败体检项含可执行的 `next_steps`。MCP 尚未启动时，仍需用户借助 README 完成客户端安装配置。
- [ ] 独立模板：`process_media(action="template")` 可列举、读取、复制三套模板；安装包带原资源/许可；只写新的授权目录，不覆盖原件，也不把样例 PDF 当作实际导出。客户端不支持 Resources 时仍能使用工具路径。
- [ ] 负例：FFmpeg 缺失时 `health_check` 明确报告；不支持链接 `inspect_video` / `generate_note` 给出清晰错误。
- [ ] `docs/` 文档齐全且与实现一致，每个关键节点在 `CHANGELOG.md` 有记录。

## 暂不做的（v2 候选）

- **RAG 问答 / ChromaDB** —— agent 自己读 Markdown，若后续需要可用可再引入。
- **MCP 内置 PDF/DOCX 自动渲染** —— 当前不提供渲染工具。agent 可复用笔记和独立模板，在用户授权的本机终端编译 PDF；缺少编译器/字体/依赖时交付源码，不宣称 PDF 已生成。
- **与上游自动同步** —— 目前手动同步（`VENDOR.md` 有步骤），后续可加 CI 检查差异。
