# 文档索引

## 阅读路径

- **新 Agent 接手** → 先读 [00-新手上路.md](00-新手上路.md)（当前状态 + 约定 + gotchas，10 分钟上手）。
- **改代码前** → [02-架构设计.md](02-架构设计.md)（数据流、模块边界、工具表）+ [VENDOR.md](../VENDOR.md)（vendored 同步纪律）。
- **用户侧/操作/排障** → [04-使用手册.md](04-使用手册.md)。
- **查历史**（条目号 / 批次号 / 节点）→ 用 grep 定位 `05` / `06` / `CHANGELOG`，**不要通读**。

## 关键节点

1. **仓库脚手架** —— 建仓、目录结构、文档骨架
2. **核心代码移植** —— 从上游流水线项目复制核心模块并剥离 FastAPI
3. **MCP 服务** —— FastMCP server 与 10 个工具
4. **Skill** —— agent 工作流文档
5. **打包与安装** —— pyproject 依赖、install.sh、注册说明
6. **验证** —— 端到端测试
7. **审计收敛** —— 16 轮全库扫描（`05`/`06`），708 tests 基线

## 更新纪律

- 改用户可见行为 → 同步 `04` + `skills/videonote/reference/tools.md` + SKILL.md。
- 审计/扫描轮次 → 登记 `05`（候选条目）+ `06`（批次日志）+ `CHANGELOG`。
- 改架构/工具数 → 同步 `02` 与本文档。
