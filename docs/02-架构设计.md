# 02-架构设计

## 总体数据流

```
视频链接 (URL / file:// / 本地路径)
   │
   ▼  ① detect_platform
      内置：bilibili / youtube / douyin / tiktok / kuaishou / local
      其它 URL → generic（yt-dlp 1800+ 站点）；仅显式 platform=unsupported 才 handoff
   │
   ▼  ② 下载（yt-dlp 适配器）或本地直读
音频 / 视频 + 元信息 → note_results/{task_id}/raw/
   │
   ▼  ③ 字幕优先；无则转写
      引擎：fast-whisper / mlx-whisper / funasr / groq / bcut / kuaishou
      可选：预处理（16kHz 归一 + 超长分块）/ 说话人分离（独立工具）
TranscriptResult → note_results/{task_id}/gen/transcript.json
   │
   ▼  ④ LLM 总结（GPT 工厂，按 provider_id）或停在素材包
Markdown / material
   │
   ▼  ⑤ 后处理（截图、链接、源链接前缀、可选 SRT/VTT/JSON 导出）
   │
   ▼  ⑥ 落盘：note_results/{task_id}/{status.json, result.json, manifest.json, raw/, gen/}
      全局索引：SQLite video_tasks（list_tasks）
```

Agent 时序：`generate_note` 或 `prepare_note_material`（拿到 `task_id`）→ 轮询 `get_task_status`（**不要**用 `wait_for_note`，会卡住 stdio）→ 读 `result.markdown` / `get_task_transcript`。

## 运行时约定（`videonote_mcp/config.py` 在 import `app.*` 之前设置）

| 环境变量 | 默认值 | 说明 |
|----------|--------|------|
| `VIDEONOTE_DATA_DIR` | 源码 `<仓库>/data`；安装包 `~/.local/share/videonote-mcp` | 数据根；`VIDEONOTE_DATA_DIR` 可覆盖 |
| `DATABASE_URL` | `sqlite:///<data>/video_note.db` | SQLite（engine 在 import 时读） |
| `NOTE_OUTPUT_DIR` | `<data>/note_results` | 任务文件夹 |
| `IMAGE_OUTPUT_DIR` | `<data>/static/screenshots` | 截图（`note.py` 必须读这个名字，不是 `OUT_DIR`） |

| `VIDEONOTE_CONFIG_DIR` | `<data>/config` | transcriber / cookie / app_config |

## 异步任务与任务文件夹

- `generate_note` / `prepare_note_material` / `transcribe_media` / `extract_frames` / `summarize_note` 都是异步：立即返回 `task_id`，后台 `ThreadPoolExecutor` 执行。
- 布局：`note_results/{task_id}/status.json` + `result.json` + `manifest.json` + `raw/` + `gen/`。**不是**扁平的 `{task_id}.json`。
- 状态枚举：`PENDING → INITIALIZING → PARSING → DOWNLOADING → TRANSCRIBING → SUMMARIZING → FORMATTING → SAVING → SUCCESS/FAILED/CANCELLED`。
- 未知 `task_id`（没有 `status.json`）返回 **`NOT_FOUND`**，不是 PENDING。
- 步骤任务也会 `insert_video_task`，`list_tasks` 能看见。
- `get_task_status` 默认剥掉完整转写；用 `get_task_transcript` 按需取。

## MCP 工具（37 个）

凭证红线：**API key / Cookie / HF token 不能经 MCP 工具传入**。填 key 走 `! videonote providers set`；B 站 Cookie 走 `! videonote login bilibili` / `! videonote setup`。

| 分组 | 工具 | 要点 |
|------|------|------|
| 端到端 | `generate_note` | `provider_id` 可省略（默认供应商 / 唯一已填 key）；认 `file://`；同视频（`platform:video_id`）复用上次转写缓存 |
| 素材包 | `prepare_note_material` | 不调 LLM；同样认 `file://`；同样吃转写缓存 |
| 状态 | `get_task_status` / `get_task_transcript` / `list_tasks` / `cancel_note` | 未知 id → NOT_FOUND |
| 已废弃 | `wait_for_note` | 不再 sleep，立刻返回快照 + `deprecated`；请用 `get_task_status` |
| 步骤 | `fetch_subtitles` / `transcribe_media` / `extract_frames` / `summarize_note` | 后三个异步，成功会写 SUCCESS |
| 评论 | `fetch_comments` / `fetch_danmaku` | 仅 B 站 |
| 配置 | `list_providers` / `add_provider` / `update_provider` / `delete_provider` / `list_models` / `add_model` / `delete_model` / `test_provider` / `read_app_config` | add/update **拒绝** api_key；test 用已存 key；read_app_config 过滤敏感项 |
| 转写 | `get_transcriber_config` / `set_transcriber` / `list_transcriber_models` / `download_transcriber_model` | 含 funasr |
| 系统 | `health_check` / `preflight` / `validate_url` / `inspect_video` | health 含 `server_version`、队列；preflight 提交前体检（ffmpeg/磁盘/转写器/key/时长）；inspect 拆分 P / 播放列表为可提交 url |
| Cookie | `set_downloader_cookie` | **拒绝写入**，引导 CLI |
| 导出 / 音频 | `export_transcript` / `merge_audio` / `diarize_media` | diarize **拒绝** hf_token 参数 |
| 清理 | `get_task_files` / `cleanup_note` / `cleanup_all` | cleanup_all 默认不动 DB |

## 关键设计决策

1. **跨任务转写缓存**：同一视频（`platform:video_id`）再次生成，把上次转写从 `<数据目录>/note_cache/` 拷进 `gen/transcript.json` —— 下游 `has_transcript → skip_download` 自动跳过下载与转写。身份从 URL 预解析（B 站 BV+p / YouTube / 抖音 / TikTok；本地 sha256）；转写按来源分键（`subtitle` / `引擎[:尺寸]`），换引擎/尺寸不误用。`cleanup_all` 一并清。
2. **无 RAG**：agent 读 Markdown / 转写，省去向量库。
3. **本地 + 云端转写并存**：默认 `fast-whisper`；可切 mlx / funasr / groq / bcut / kuaishou。
4. **后台线程 + 并发上限 3**：会话内可排队多个任务，但不要在同一条消息里并行塞多个 `generate_note`（客户端不稳）。
5. **密钥不进对话**：MCP 工具拒收 key/cookie/token；CLI 写 SQLite / config（目前仍明文，Wave C 再上 keyring）。
6. **generic 兜底**：未知 URL 先 yt-dlp，失败再让 Agent handoff。
