# 02-架构设计

可编辑全景图：[videonote-mcp-architecture.excalidraw](videonote-mcp-architecture.excalidraw)。以本文和实现代码为准；图中不包含个人运行配置。

## 总体数据流

```
视频链接 (URL / file:// / 本地路径)
   │
   ▼  ① detect_platform
      内置：bilibili / youtube / douyin / tiktok / kuaishou / xiaoyuzhou / xiaohongshu / local
      其它 URL → generic（yt-dlp 1800+ 站点）；仅显式 platform=unsupported 才 handoff
   │
   ▼  ② 下载（平台原生下载器 / yt-dlp 适配器）或本地直读
音频 / 视频 + 元信息 → note_results/{task_id}/raw/
   │
   ▼  ③ 平台字幕优先（YouTube / B 站 / 小宇宙官方文稿）；无则转写
      引擎：fast-whisper / mlx-whisper / funasr / groq / bcut / kuaishou
      可选：预处理（16kHz 归一 + 超长分块）/ 说话人分离（经 `process_media` 调用）
      任务取消通过 `cancel_event` 在各阶段边界协作传播
TranscriptResult → note_results/{task_id}/gen/transcript.json
   │
   ▼  ④ LLM 总结（GPT 工厂，按 provider_id）或停在素材包
Markdown / material
   │
   ▼  ⑤ 后处理（截图、链接、源链接前缀、可选 SRT/VTT/JSON 导出）
   │
   ▼  ⑥ 落盘：note_results/{task_id}/{status.json, result.json, manifest.json, raw/, gen/}
      全局索引：SQLite video_tasks（list_tasks）
```

Agent 时序（#151）：默认 `prepare_note_material`（拿到 `task_id`）→ 轮询 `task` → 读转写/帧，由当前对话 Agent 写笔记。后备（Agent 无法看图或用户要求配置 LLM）才走 `generate_note` / `batch_generate_notes` → 读 `result.markdown`。

| `IMAGE_BASE_URL` | `file://<screenshots>` | Markdown 图片前缀 |
| `TRANSCRIBER_TYPE` | `fast-whisper` | 可被 `videonote transcriber set` / 配置文件覆盖 |

| `VIDEONOTE_MAX_WORKERS` | `3` | 单进程并发任务上限 |
| `VIDEONOTE_CONFIG_DIR` | `<data>/config` | transcriber / cookie / app_config |
| `VIDEONOTE_STDERR_LOG_MAX_MB` | `50` | `mcp_stderr.log` 轮转阈值（超限重命名 `.log.1`）；非法值回退默认 |
| `VIDEONOTE_CACHE_TTL_DAYS` | `30` | 跨任务转写缓存滑动 TTL（天）；命中刷新；`0` 不过期；非法值回退 30 |
| `VIDEONOTE_CACHE_MAX_MB` | `2048` | 跨任务转写缓存总量上限（MB）；超限按身份目录 LRU 淘汰；`0` 不限制 |

Claude Code 插件 `userConfig` 会注入 `VIDEONOTE_*`；跳过的项可能是字面 `${user_config.x}` 或空串，`_purge_placeholder_env()` 会剔除。

## 异步任务与任务文件夹

- `generate_note` / `prepare_note_material` / `batch_generate_notes` 提交后由后台 `ThreadPoolExecutor` 异步执行：立即返回 `task_id`，再由 `task` 轮询。普通任务受 admission 限制并预占名额覆盖排队与执行；batch 通过 thread-local bypass 不占普通 admission 名额，由线程池排队。`inspect_video`、`health_check`、`get_config`、`list_tasks`、`process_media`、`cleanup` 为同步工具。
- `process_media` 是同步媒体加工入口，不创建后台任务、不登记 `_task_futures`/`_task_events`，因此没有对应 `task_id` 可供 `task(action="cancel")` 控制；第三方阻塞调用仍只能自然返回。
- 布局：`note_results/{task_id}/status.json` + `result.json` + `manifest.json` + `raw/` + `gen/`。**不是**扁平的 `{task_id}.json`。
- 状态枚举：`PENDING → INITIALIZING → PARSING → DOWNLOADING → TRANSCRIBING → SUMMARIZING → FORMATTING → SAVING → SUCCESS/FAILED/CANCELLED`。
- 未知 `task_id`（没有 `status.json`）返回 **`NOT_FOUND`**，不是 PENDING。
- 步骤任务也会 `insert_video_task`，`list_tasks` 能看见。
- `task`（status）默认剥掉完整转写；用 `task`（transcript）按需取。

## MCP 工具（10 个）

凭证红线：**API key / Cookie / HF token 不能经 MCP 工具传入**。填 key 走 `! videonote providers set`；B 站 Cookie 走 `! videonote login bilibili`；小宇宙官方文稿走 `! videonote login xiaoyuzhou`；小红书走 `! videonote login xiaohongshu`；抖音走 `! videonote login douyin` / `! videonote setup`。转写全文另可走 **MCP Resource** `videonote://task/{task_id}/transcript`（时间轴纯文本，不占工具数）。

**#135 工具精简（39→18）**：删除全部写配置工具（供应商/模型/转写器/Cookie CRUD——配置修改一律走 CLI，MCP 面零写配置入口）与流水线步骤工具（`fetch_*` / `transcribe_media` / `extract_frames` / `summarize_note`——端到端 `generate_note` 内部已含全部步骤，步骤工具暴露面冗余）。只读配置合并为单一 `get_config`。**#138 再精简（16→10）**：状态/转写/取消合并为单一 `task`（action 分派），清理合并为 `cleanup`，导出/合并/说话人分离合并为 `process_media`，`preflight` 并入 `health_check`。

| 分组 | 工具 | 要点 |
|------|------|------|
| 生成 | `prepare_note_material` | **默认路径**：不调 LLM；认 `file://`；吃转写缓存；当前 Agent 写笔记 |
| 生成 | `generate_note` | **后备 LLM**：`provider_id` 可省略；认 `file://`；同视频复用转写缓存 |
| 生成 | `batch_generate_notes` | **仅后备 LLM**：播放列表/分 P 服务端展开+逐个排队（`max_entries` 上限）；单条失败不阻断 |
| 解析 | `inspect_video` | 识别平台 + 检查链接 + 拆分 P / 播放列表（#136 并入 validate_url）；抖音用原生签名详情接口，不走 yt-dlp，返回统一 `/video/{id}` |
| 任务 | `task` | action=status / transcript / cancel；未知 id → NOT_FOUND；轮询用 status，转写按需取；cancel 只发协作式事件，下一阶段边界生效，不能硬中断第三方阻塞调用；B 站弹幕/评论聚合也接收取消事件 |
| 任务 | `list_tasks` | 列出全部任务（全局索引，带语义标题） |
| 配置（只读） | `get_config` | `app_config` 默认值（过滤敏感项）+ `providers`（key 掩码）+ `transcriber` 就绪 + `cookie_configured`（平台名）；传 `provider_id` 附加连通性探测（用已存 key）。**修改一律走 CLI** |
| 系统 | `health_check` | 提交前体检：ffmpeg / 磁盘 / 转写器 / 任务队列；`need_provider` 默认 False；后备 LLM 传 True 才查供应商；`url` 非空时顺带预解析时长；含 `server_version` |
| 媒体处理 | `process_media` | action=template（独立模板列举/文本读取/复制到新目录，不编译）/ export（转写导出 srt/vtt/json）/ merge（多文件合并 16kHz mono wav）/ diarize（说话人分离；**拒绝** hf_token 参数）；同步执行，不登记任务注册表，不能用 `task(action="cancel")` 控制 |
| 清理 | `cleanup` | 传 `task_id` 按任务清理（含 `dry_run` 先查后清）；不传 = 全局清理（同步清空全局索引；config/models 默认保留；logs 不清） |

> 内部保留：`_stage_label`（`task` status 内部用，不再暴露为工具）；弹幕/评论/字幕抓取在 `generate_note` / `prepare_note_material` 内部完成（`include_comments` 参数）。

## MCP 自描述与独立模板

- `guidance.py` 是服务器初始化说明与诊断下一步的共同来源；官方仓库通过 `websiteUrl`、`instructions` 以及 health/config 的 `project` 暴露。客户端可能忽略初始化说明，所以工具描述仍保留关键提示。README 负责 MCP 尚未启动时的安装说明；联网文档必须匹配实际运行版本。
- `export/templates.py` 仅管理三套白名单模板；`templates/` 的源码、许可证、配图和预览随 wheel 分发。`process_media(action="template")` 是客户端不支持 Resources 时的完整后备入口；只读默认无副作用，复制显式 `out_dir`，拒绝已有目录、路径穿越、包内不安全软链与越界写入。
- Resources：`videonote://templates`（目录）、`videonote://templates/{template_id}`（文件清单）、`videonote://help/export`（随包指南），加上原任务转写 Resource。不增加工具数，不恢复 Skills/commands。
- 模板副本附带原许可证；它不是已渲染用户文档，不自动运行编译器/安装依赖。Agent 用底稿生成源文件，PDF 需实际编译验证。复制到独立 `exports/` 的模板不登记任务 manifest，也不由任务 cleanup 回收。
- CI 使用 `tests/mcp_stdio_smoke.py` 在无关工作目录验证源码和 wheel 的初始化、10 工具精确名单、离线模板与许可证复制。

## 关键设计决策

1. **跨任务转写缓存**：同一视频（`platform:video_id`）再次生成，把上次转写从 `<数据目录>/note_cache/` 拷进 `gen/transcript.json` —— 下游 `has_transcript → skip_download` 自动跳过下载与转写。身份从 URL 预解析（B 站 BV+p / YouTube / 抖音 / TikTok / 小宇宙 eid / 小红书笔记 id；本地 sha256）；转写按来源分键（`subtitle` / `引擎[:尺寸]`），换引擎/尺寸不误用。默认滑动 TTL 30 天、总量 2048MB（按身份目录 LRU）；全局 `cleanup` 一并清。
2. **无 RAG**：agent 读 Markdown / 转写，省去向量库。
3. **本地 + 云端转写并存**：默认 `fast-whisper`；可切 mlx / funasr / groq / bcut / kuaishou。
4. **后台线程 + 并发上限 3**：会话内可排队多个任务，但不要在同一条消息里并行塞多个 `generate_note`（客户端不稳）。`batch_generate_notes` 有意旁路该上限。
5. **密钥不进对话**：MCP 工具拒收 key/cookie/token；CLI 写 SQLite / config——落盘前经 Fernet（机器本地密钥 `fernet.key`，0600）加密，`providers`/`app_config` 读写自动加解密；MCP 响应恒掩码。
6. **generic 兜底**：未知 URL 先 yt-dlp，失败再让 Agent handoff。
7. **协作式取消**：任务持有 `threading.Event`，在字幕、下载、ASR、预处理、ffmpeg、抽帧、说话人分离、B 站弹幕/评论聚合、GPT chunk/后处理等边界检查并传播；可控的 ffmpeg/流式下载会终止或尽快退出，但无法硬中断正在进行的第三方 HTTP/模型推理。
8. **SQLite 迁移边界**：兼容迁移只对 SQLite 执行；`video_tasks` 缺表时 `_migrate_video_tasks` 是安全 no-op（新库仍由 `create_all` 建表）；迁移执行异常不再吞掉，而是记录并 re-raise，禁止以未知旧 schema 继续启动。
9. **持久化与并发边界**：普通任务 admission、submit、Future/Event 登记在同一 `_tasks_lock` 内，batch 明确旁路普通 admission 由线程池排队；DAO 的插入/更新/删除失败会 rollback 后 re-raise，流水线完成阶段的 `video_tasks` 索引失败因此阻止 SUCCESS。提交失败执行任务目录/manifest/索引回滚，清理失败以结构化诊断附加到原始异常，不替换原始错误。manifest 的 `RLock` 只覆盖同一进程，跨进程检查—删除 TOCTOU 仍为 P2。
10. **时长探测分层**：VideoReader 使用严格、带 120 秒超时的 ffprobe，非法时长直接失败；音频预处理的 `probe_duration` 是 best-effort，失败返回 0，由 `chunk_duration_guess` 回退 1800 秒并记录 warning。

## 抖音登录与预检边界

- `douyin_browser.py` 在可见 Chrome/Edge 中执行官方页面；只关联当前二维码的 GET/POST/WS 状态，后备轮询也在页面内执行。手机确认不等于浏览器已有登录 Cookie。
- 身份验证错误 2046 进入独立验证状态：本人在浏览器完成短信/刷脸，CLI 只提示并等待最多 5 分钟，不收验证码。取得主站可用的 session Cookie 后才保存。
- `douyin_auth.py` 的附加 HTTP 探测区分明确认证拒绝和无法确认；后者不抹除 Cookie、不一概要求重扫。
- `services/inspect.py` 复用 `DouyinDownloader.fetch_video_info` 的 Cookie、ABogus 与 msToken 路径；msToken 初始化预期失败时以空值继续尝试详情请求，仍保留取消检查，以实际详情响应判断成功。
- `utils/url_parser.py` 为下载器与转写缓存共享 aweme_id 解析：视频页、精选弹层页、分享页和短链统一身份；长链本地解析，短链经过逐跳公网 URL 校验再展开。
- 元信息可访问、浏览器已登录、媒体下载和 ASR 成功是不同状态，不能相互替代。源码与安装包的数据根默认不同；配置入口见使用手册。
